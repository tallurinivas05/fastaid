# FastAid Demo v29

- Cheeriyal is the fixed demo center; no browser GPS is used.
- Hospital dashboard has exactly three main interfaces: Ambulance Arrivals, Blood Emergency Request, Blood Request Accepts.
- Ambulance Arrivals only shows ambulances travelling to the selected hospital and displays Captain → Hospital distance and ETA.
- Hospital maps are fixed/static; only the ambulance marker moves along the predefined demo route.
- Nearby fictional demo blood banks are listed with distance and available units.
- Blood request acceptance is separated from the blood-request interface and includes fictional incoming hospital requests.
- No coordinates are displayed in the UI.
